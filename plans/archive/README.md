# Plans Archive

This directory contains historical plans that are **reference-only**.

## Subdirectories

| Directory | Contents | Era |
|-----------|----------|-----|
| `pre_v1/` | Pre-R1.5 plans: original MASTER_PLAN, R0 protocols, wave plans, comparator designs | Before 2026-03 |
| `v1_root/` | R1.5-era root plans: r1_5_training_plan, r1_5_forward_decision_tree, follow-ups | 2026-03 |
| `v1_sessions/` | R1.5-era session plans: diagnostics, ablations, workflow redesigns | 2026-03 |

## Rules

- **Do not resume archived work.** These plans are historical context only.
- **Do not execute commands from archived plans.** Scripts, configs, and flags may have changed.
- **The active governing plan is always in `CLAUDE.md` "Active Governing Plans" table.**
- If an archived plan conflicts with an active governing plan, the active plan wins.
- If you need context about why a decision was made, archived plans are useful reading.
  But they do not govern current execution.
