### 1. Extract `_should_timeout()` helper (`review_driver.py`)

Extract the boolean at lines 1517–1519 into a named function:

```python
def _should_timeout(
    elapsed: float, max_runtime_s: float, current_state: ReviewState
) -> bool:
    """Check if the review loop should timeout.

    Normal timeout fires when elapsed > max_runtime_s, UNLESS state is
    READY_TO_MERGE (let merge complete). A hard grace-period cap fires
    regardless of state to prevent unbounded loops.
    """
    grace_period_s = 60
    # Hard cap: always timeout after grace period, regardless of state
    if elapsed > max_runtime_s + grace_period_s:
        return True
    # Normal timeout: skip if READY_TO_MERGE (let merge proceed)
    if elapsed > max_runtime_s and current_state != ReviewState.READY_TO_MERGE:
        return True
    return False
```

Then replace the inline condition in `main()` with `_should_timeout(elapsed, max_runtime_s, loop_state.current_state)`.
