## Findings Triage

### Fix (HIGH — bugs on main)

**F1-A: `compact_session` cleanup rmtree can mask original exception**
- File: `src/bid_euchre/ops/compaction.py:213-214`
- The `except OSError` handler calls `shutil.rmtree(session_dir)` to clean up
  a partial archive. If `rmtree` itself raises (e.g., `PermissionError`), it
  masks the original exception that caused the failure.
- Fix: Wrap cleanup `rmtree` in `try/except OSError` to prevent masking.

**F1-B: `delete_archive` has no error handling on `shutil.rmtree`**
- File: `src/bid_euchre/ops/compaction.py:330`
- `shutil.rmtree(session_dir)` is called with no try/except. A `PermissionError`
  on a read-only file propagates uncaught. Inconsistent with `compact_session`
  in the same module which handles `OSError`.
- Fix: Wrap in `try/except OSError`, log warning, return `False` on failure.

**F2: Python 3.10 `Z`-suffix silently defeats timestamp fix**
- File: `src/bid_euchre/ops/status.py:286` (`_parse_iso_timestamp`)
- `datetime.fromisoformat()` doesn't handle `"Z"` suffix on Python 3.10
  (only 3.11+). The function returns `None` on parse failure, silently
  defeating the parsed-timestamp comparison fix from PRs #998/#999.
  Project `requires-python = ">=3.10"`.
- Fix: Normalize `"Z"` → `"+00:00"` before calling `fromisoformat()`.

### Fix (MEDIUM — design/quality)

**F5: Cumulative daemon error counter should be consecutive**
- File: `src/bid_euchre/ops/scheduler.py:357,376`
- `result.errors.extend(tick_result.errors)` accumulates all errors across
  all ticks. `len(result.errors) >= 3` triggers shutdown. 3 errors spread
  across 100 ticks stops the daemon. For long-running daemon this is overly
  aggressive; test name says "stops on repeated errors" implying consecutive.
- Fix: Track a `consecutive_errors` counter, reset on successful ticks.
  Keep cumulative errors in `result.errors` for logging, but only stop on
  3 consecutive failures.

**F6: `_emit_retry_event(policy: object)` loses type safety**
- File: `scripts/internal/ops.py:511-512`
- `policy` typed as `object`, accessed via `getattr()`. Actual type is
  `RetryPolicy` from `bid_euchre.ops.recovery`. Loses IDE support.
- Fix: Import and type as `RetryPolicy`.

## Implementation Plan

### Task 1: Fix compaction error handling (F1-A, F1-B)

**File:** `src/bid_euchre/ops/compaction.py`

F1-A (line ~213):
```python
# Before
if session_dir.exists():
    shutil.rmtree(session_dir)

# After
if session_dir.exists():
    try:
        shutil.rmtree(session_dir)
    except OSError as cleanup_err:
        logger.warning(
            "Failed to clean up partial archive %s: %s",
            session_dir, cleanup_err,
        )
```

F1-B (line ~330):
```python
# Before
shutil.rmtree(session_dir)

# After
try:
    shutil.rmtree(session_dir)
except OSError as e:
    logger.warning("Failed to delete archive %s: %s", session_dir, e)
    return False
return True
```
