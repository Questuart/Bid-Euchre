### Possible Root Cause

Two patterns could explain the auto-close failure:
1. **Dual-PR references** (#1852, #2076): When multiple PRs reference the same
   issue with "Closes", the first merge may not trigger auto-close if both PRs
   exist simultaneously.
2. **Late-day batch merges**: 5 of 8 issues are from PRs merged after 21:00 UTC,
   possibly during a high-throughput merge window where GitHub webhooks were delayed.
